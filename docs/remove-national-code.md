# حذف کد ملی از حساب کاربری

فیلد کد ملی از فرم، شمارندهٔ تکمیل اطلاعات، پیام راهنما، تایپ‌ها، مدل User و دادهٔ ارسالی به API حذف شده است. API فقط فیلدهای حساب مورد نیاز رابط کاربری را برمی‌گرداند و مقدار ارسالی کلاینت قدیمی را ذخیره نمی‌کند.

## پاک‌سازی دیتابیس

در ۲۰۲۶-۱۱-۰۸، فیلد `nationalCode` با `$unset` از ۴ سند در `test.users` دیتابیس فعال سایت حذف شد. شمارش پس از عملیات صفر بود. سایر فیلدها و سندهای کاربران حفظ شدند؛ مقدار کد ملی در گزارش یا خروجی ذخیره نشد. ایندکسی برای این فیلد وجود نداشت. دیتابیس‌های بک‌آپ قدیمی تغییری نکردند.

تغییر دیتابیس مستقل از انتشار کد است. تا زمانی که نسخهٔ جدید روی سرور منتشر نشود، نسخهٔ فعلی سایت همچنان می‌تواند فیلد قدیمی را ثبت کند. بعد از انتشار و جایگزینی تمام پردازش‌های قبلی، اسکریپت زیر را دوباره اجرا کنید تا مقادیر احتمالی این فاصله نیز پاک شوند.

پیش‌نمایش (فقط تعداد، بدون نمایش مقادیر یا تغییر داده):

```bash
node --env-file=.env scripts/remove-user-national-code.mjs
```

حذف و شمارش مجدد:

```bash
node --env-file=.env scripts/remove-user-national-code.mjs --apply
```

اسکریپت از دیتابیس مشخص‌شده در `MONGODB_URI` استفاده می‌کند. اجرای دوبارهٔ آن مجاز است. فیلدهای دیگر و زمان ویرایش کاربر را تغییر نمی‌دهد. اگر پس از عملیات هنوز رکوردی حاوی این فیلد باشد، کد خروجی غیرصفر خواهد بود. پس از بازیابی بک‌آپ قدیمی نیز همین پاک‌سازی را اجرا کنید.

## بررسی

- تست API: حذف دادهٔ قدیمی از پاسخ GET و PUT، نادیده‌گرفتن ورودی کلاینت قدیمی، حفظ ویرایش‌های مجاز و تبدیل تاریخ، کنترل ورود و کاربر ناموجود.
- تست مدل: فیلد حذف‌شده در سند جدید ذخیره نمی‌شود.

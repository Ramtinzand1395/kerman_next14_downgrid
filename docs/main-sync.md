# رفع تداخل با main

برنچ هدف اصلاح: `fix/admin-api-access-policy`

`main` با کامیت `6d6a0aa` شامل اصلاح اعتبارسنجی مراحل نصب و استفاده از اطلاعات تماس حساب کاربر بود. برنچ اصلاحات با کامیت `b23a6cb` از آن عقب بود و گیت‌هاب پیام «Can't automatically merge» نمایش می‌داد.

تنها تداخل متنی در `GameOrderSelector.tsx` و ردیف انتخاب روز بود. رفع تداخل، هم `fieldProps("selectedDate")` برای شناسه و وضعیت خطا را نگه می‌دارد و هم `min-w-0 max-w-full` برای جلوگیری از سرریز افقی را. سایر اصلاحات `main`، از جمله اعتبارسنجی، خلاصهٔ حساب، بازیابی پیش‌نویس و callback ورود، نیز با سیاست دسترسی و اصلاحات این برنچ ترکیب شدند.

اعتبارسنجی نسخهٔ ترکیبی: ۲۴۳ تست کل، ۲۴۲ موفق، صفر شکست و یک تست اختیاری POS اجرا نشده؛ بررسی TypeScript با کنترل متغیرها و پارامترهای استفاده‌نشده و بیلد production موفق هستند.

بررسی مرورگر محلی با دادهٔ ساختگی، پنج مرحلهٔ نصب با پیک، آدرس بلند، خطای انتخاب خدمت/روز/ساعت، نگه‌داری آدرس پیش‌فرض، نمایش اطلاعات حساب و شکست یک API اختیاری را در عرض‌های ۳۹۰ و ۱۳۶۳ پیکسل پوشش می‌دهد. هیچ درخواست یا پرداخت واقعی ثبت نشده است.

این ادغام فقط `main` را وارد برنچ اصلاحات می‌کند. برنچ `main` و سایت زنده تغییر نکرده‌اند؛ انتشار نهایی از طریق PR جداگانه انجام می‌شود.
